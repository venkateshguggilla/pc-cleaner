# PC Cleaner

A small Windows cleaner (Python + tkinter with [ttkbootstrap](https://github.com/israel-dryer/ttkbootstrap)
Bootstrap styling) for temp files, Explorer history, browser history/cache and media-player recent lists.
Light and dark themes (moon/sun button, remembered), sharp on high-DPI displays.

## Run

```
python -m pip install -r requirements.txt   # once: ttkbootstrap
run.bat                      # double-click: opens the window
python -m pccleaner          # same, from a terminal
python -m pccleaner list     # ids of everything detected on this PC
python -m pccleaner scan     # what would be deleted (deletes nothing)
python -m pccleaner clean edge.cache firefox.cache    # clean specific items (asks first)
```

In the window: tick items on the left → **Analyze** → **Run Cleaner**. Selections are
remembered in `%APPDATA%\PCCleaner\settings.json`. Items marked *(admin)* need
**Restart as administrator**.

### Standalone exe

`build.bat` runs the tests and then builds `dist\PCCleaner.exe` (one ~22 MB file, no Python needed;
requires `python -m pip install -r requirements.txt pyinstaller`). The icon is generated by `tools\make_icon.py` and the
version shown in Properties comes from `tools\version_info.txt`. The exe accepts the same commands
(`PCCleaner.exe scan`, `PCCleaner.exe large ...`) but, being a windowed app, prints no output.
### Installer

`build_installer.bat` builds the exe and then `installer\Output\PCCleaner-Setup-<version>.exe`
with [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`);
the script is `installer\PCCleaner.iss`. Setup installs for the current user by default (no admin
prompt, `%LOCALAPPDATA%\Programs\PC Cleaner`) or for all users if chosen, adds a Start menu entry,
an optional desktop icon and an entry in Settings → Apps. Uninstalling removes the scheduled task and
asks whether to delete settings/reports. Silent: `PCCleaner-Setup-1.0.0.exe /VERYSILENT /CURRENTUSER`.
Bump the version in `tools\version_info.txt` before a new release.

The exe is unsigned, so Windows SmartScreen may show "Windows protected your PC" on first run
(**More info → Run anyway**), and some antivirus tools are wary of PyInstaller one-file exes.

## What it cleans

| Group | Items |
|---|---|
| Windows | user temp, Windows temp*, error reports / crash dumps, DirectX & GPU-driver shader caches, Store app caches, thumbnail cache, Windows logs*, Delivery Optimization cache*, Windows Update cache*, Recycle Bin |
| Windows Explorer | recent documents, jump lists, Run (Win+R) history, address-bar history, search history, Open/Save dialog history, clipboard, clipboard history (Win+V), ShellBags, UserAssist, Remote Desktop / network drive / Paint / WordPad history |
| Browsers | Chrome, Edge, Brave, Vivaldi, Chromium, Zoho Ulaa, Opera, Opera GX, Firefox: history, cache, cookies, saved session (all profiles) |
| Media players | Windows Media Player, VLC, MPC-HC, MPC-BE, PotPlayer recent lists |
| Apps | Microsoft Office recent files, Notepad++ recent/search history, VS Code / Insiders / VSCodium / Cursor caches and recent list, Windows Photos cache |
| Developer tools | npm, Yarn, pip, NuGet caches |

\* needs administrator. Only apps that are installed are shown.

Off by default because they're disruptive: cookies (signs you out), saved sessions,
jump lists (also removes pinned jump-list items), ShellBags (resets folder views), UserAssist
(resets Start "Most used"), thumbnail cache, Recycle Bin, Windows Update cache.

## Large file finder

**Large files...** lists the biggest files in a folder (default: your user folder) above a size
(default 100 MB), optionally only ones not changed for N days. Windows and program folders, system
files and junctions are skipped. Sort by any column, double-click to show a file in Explorer, and
select files to **Send to Recycle Bin** — never a permanent delete; Windows asks first if a file is
too big for the bin. Files that belong to programs (AppData, program folders, hidden dot-folders)
are marked *(app file)* and get an extra warning. Read-only from the command line:
`python -m pccleaner large [folder] --min-mb 200 --days 180`.

## Scheduled cleaning & reports

**Schedule...** creates a Windows Task Scheduler task named `PCCleaner` (daily or weekly at a set
time). It cleans a snapshot of the items ticked when you save the schedule, without prompts:
items whose program is open are skipped, and a run that was missed because the PC was off happens
at the next start-up. Admin items are only included if the schedule is saved while running as
administrator. `python -m pccleaner schedule` shows the current schedule; **Turn off** removes it.

Every clean (manual, command line or scheduled) writes a report to `%APPDATA%\PCCleaner\logs`
(last 50 kept) — open it with **Reports**.

## winapp2.ini (community rules for thousands of apps)

Click **Update winapp2.ini** (or run `python -m pccleaner winapp2-update`) to download the latest
[winapp2.ini](https://github.com/MoscaDotTo/Winapp2) (CC BY-SA 4.0) to `%APPDATA%\PCCleaner\winapp2.ini`.
Rules for programs detected on this PC appear in collapsed **winapp2: …** groups, all unticked;
"All" does not tick them. A rule's `Warning=` is shown when you tick it.

Supported: `Detect`, `DetectFile`, `DetectOS`, `SpecialDetect`, `FileKey` (`RECURSE`, `REMOVESELF`,
`;`-separated patterns, wildcards in folder names), `RegKey`, `ExcludeKey` (`FILE`/`PATH`/`REG`),
`LangSecRef`, `Section`, `Warning`. Extra restrictions: recursive or match-all rules on protected
folders are refused, and registry rules are limited to non-core keys under `HKCU`.

## Safety

- Files modified in the last hour are kept in temp folders (24 h for the update cache).
- Junctions/symlinks are removed as links, never followed.
- Protected folders (Windows, Program Files, your profile, Documents, Desktop, ...) are refused outright.
- Files in use are skipped and reported, not forced.
- Programs whose data is selected (e.g. Chrome, VLC) must be closed. **Run Cleaner** offers to close them:
  first politely (like clicking X, so they can save tabs or ask to save work), then — only if you agree —
  by force. Or leave them open and skip their items. Scheduled runs never close programs; they skip.
- Firefox history is removed from `places.sqlite` with SQL so **bookmarks are kept**.

## Adding a new cleaner

Add a `Target` in `pccleaner/cleaners/*.py`, built from parts:
`Files(lambda: [paths...])`, `RegKeys(r"Software\...")` or `Custom(scan_fn, clean_fn)`.

## Tests

```
python -m unittest discover -s tests -t . -v
```
Tests only touch temporary folders, a throwaway SQLite file and a throwaway `HKCU\Software\PCCleanerTest_*` key.
